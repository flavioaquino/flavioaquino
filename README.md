# Olá! Sou Flávio Basílio 👋

**Engenheiro de Software | Analista de TI | Cientista da Computação (UFPI)**

Sou um profissional de tecnologia apaixonado por resolver problemas complexos através do desenvolvimento de software e da inteligência artificial. Com uma base que se estende da infraestrutura de redes ao desenvolvimento Full-Stack, atualmente atuo como Analista de TI na STRANS e como Engenheiro de Software Freelancer, desenvolvendo soluções sob medida para clientes.

Tenho focado grande parte dos meus estudos e projetos na arquitetura de sistemas modulares e inteligentes. Um dos meus principais trabalhos é o *Fiscalizer Agent*, uma plataforma de monitoramento de tráfego em tempo real impulsionada por Visão Computacional (YOLO, TensorRT).

## 🚀 Foco de Atuação

* **Inteligência Artificial & Visão Computacional:** Treinamento e implementação de modelos de detecção em tempo real para automação de processos.
* **Desenvolvimento Full-Stack:** Criação de aplicações web robustas e APIs escaláveis (Node.js, React, PostgreSQL).
* **Infraestrutura & DevOps:** Gerenciamento de servidores Linux, redes corporativas e conteinerização de aplicações com Docker.
